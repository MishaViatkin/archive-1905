# АРХИВ 1905 · Екатеринбург

Цифровое сопровождение аналитической работы по дисциплине «Отечественная история» — **Революция 1905–1907 годов в Екатеринбурге: от рабочего подполья до первого Совета депутатов**. УрФУ, кафедра отечественной истории, студенты группы ЭУ-153604.

Работа сознательно опирается **только на опубликованные и общедоступные источники**: документальные сборники, рецензируемые научные статьи (КиберЛенинка, НЭБ), монографии из фондов Библиотеки УрФУ. Архивные шифры не приводятся — см. раздел «Источниковая база» на сайте.

## Стек

- **Next.js 16** (App Router, Turbopack) + **TypeScript**
- **Tailwind CSS 4** + кастомная архивно-газетная тема
- **Framer Motion**, d3 (для атласа)
- Полностью статический предрендер (12 маршрутов)

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
npm run build
npm start
```

## Содержание (по разделам работы)

- **§1 Контекст** — условия труда, кризис 1900–1903, «Кровавое воскресенье», Русско-японская война.
- **§2 Екатеринбург накануне** — 4 предприятия (Обзор Пермской губернии за 1904 г.), стачки 1900–1904, подполье.
- **§3 Хронология** — весна 1905, стачка ВИЗ (7–14 мая), Манифест 17 октября, месяц митингов, погром 19 октября, Совет 16 ноября, разгром декабря 1905 — января 1906.
- **§4 Последствия** — боевые дружины (120–150 большевиков + 60–70 эсеров), постсоветская переоценка (Чернов, Микитюк), топонимика, преемственность 1905→1917.
- **§5 Историография** — советская (сборник 1956), постсоветская (Чернов 2005, Микитюк 2010), «генеральная репетиция» (Харитонов 1993).
